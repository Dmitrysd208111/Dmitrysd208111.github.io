# Проверка качества VELTRIX

Дата: 20 октября 2026.

## Автоматическая проверка

Фактически выполнено на Node.js 24.18.0:

| Проверка                         | Результат                          |
| -------------------------------- | ---------------------------------- |
| `npm run typecheck`              | Пройдена                           |
| `npm run lint`                   | Пройдена, без предупреждений       |
| `npm test`                       | 37 тестов, 10 файлов, все пройдены |
| `npm run build`                  | Пройдена, результат в `dist/`      |
| `npm run format:check`           | Пройдена                           |
| `npm audit --audit-level=low`    | 0 уязвимостей на момент проверки   |
| HTTP dev-server `/` и `/catalog` | 200 для обоих URL                  |
| Локальные фотографии             | Проверено наличие всех 96 файлов   |

Тесты выполняются в Vitest / jsdom: они проверяют DOM и бизнес-логику, но не реальную раскладку страницы, реальные браузеры или производительность. Production-сборка сообщает два предупреждения об аннотациях `@__PURE__` внутри зависимости Zod; Rollup удаляет эти комментарии и успешно завершает сборку. Собственный код не вызывает ошибок сборки или линтера.

Vite на Windows использует polling для наблюдения за файлами: это устраняет обнаруженный `EBUSY` при добавлении файлов на диске F:. Production Vercel не запускался; основной сайт опубликован на GitHub Pages.

## Публикация и браузерная проверка — 22 октября 2026

GitHub Actions успешно выполнил typecheck, lint, 37 тестов, production-сборку и публикацию. Адрес: https://dmitrysd208111.github.io/.

Через HTTP проверены главная, `/catalog/`, `/cart/`, `/product/apple-airpods-max-silver/` и локальное изображение товара: все ответы 200. HTML использует собранные JS-ресурсы из `/assets/`. Скрипт `prepare-pages.mjs` создаёт 45 отдельных точек входа для известных маршрутов и `404.html` для неизвестных.

В браузере фактически проверены отображение главной, переход в каталог и переход в карточку AirPods Max. Карточка осмотрена на ширине 390px; временный размер браузера сброшен после проверки. Настоящие снимки сохранены в `docs/screenshots/` и добавлены в README. Ранее локальный URL был недоступен браузерному инструменту; опубликованный сайт удалось проверить.

Замеры Lighthouse, полный обход всех ширин и полный браузерный сценарий оформления пока не выполнены. Unit/integration tests не подменяют эти проверки.

## Ручная приёмка перед публикацией

- [ ] Ширины 320, 375, 390, 768, 1024 и 1440px: нет горизонтальной прокрутки, текст и кнопки не перекрываются.
- [ ] Главная: hero, все категории, популярные вкладки, обе подборки и footer ведут по правильным маршрутам.
- [ ] Каталог: поиск с задержкой, сочетание категории / бренда / цены / наличия, сортировка, пустая выдача, сброс.
- [ ] Скопировать URL с фильтрами в новую вкладку; проверить Back / Forward и обновление страницы.
- [ ] На телефоне открыть меню и диалог фильтров; проверить закрытие по Escape, фон диалога и восстановление фокуса.
- [ ] Страница товара: все фотографии, выбор комплекта, изменение количества, блокировка остатка, избранное.
- [ ] Корзина: изменение количества, удаление, оба комплекта одного товара, сохранение после перезагрузки.
- [ ] Доставка: суммы 29 999 ₽ и 30 000 ₽, курьер / самовывоз; итог совпадает с суммой строк.
- [ ] Форма: пустые контакты, неправильные email и телефон, адрес курьера, согласие; успешное подтверждение без сети и без реальной оплаты.
- [ ] Клавиатура: skip-link, видимый focus, Enter на ссылках и кнопках, Tab по форме, фокус в диалоге.
- [ ] `prefers-reduced-motion`: микроанимации сокращены, интерфейс остаётся работоспособным.
- [ ] DevTools: отсутствуют ошибки в console и 404 на изображения; отключение изображения даёт понятный fallback.
- [x] Сохранить настоящие скриншоты в `docs/screenshots/` и добавить в README.
- [ ] После Vercel Deploy: прямой вход на вложенный URL и обновление страницы.

## Отсутствующие интеграции

Оплата, backend, письма, синхронизация устройств, реальные остатки и личный кабинет намеренно отсутствуют. Магазин — демонстрация frontend-сценариев, а не коммерческая система.
